Guest Communication Kit

AI Prompt Pack: Message Customizer

Use these prompts to tailor the templates to your specific property, voice, and platform. Copy any prompt into ChatGPT, Claude, or any AI tool.

Prompt 1: Customize All Templates for Your Property

Generates a complete set of messages tailored to your property in one shot.

I'm a short-term rental host. I need you to customize a set of guest communication templates for my specific property.

Here are my property details:
- Property name: [e.g., "Mountain View Suite"]
- Location: [e.g., "Frisco, Colorado — 5 min from Main Street, 15 min from Breckenridge ski resort"]
- Property type: [e.g., "1-bedroom condo in a quiet complex"]
- Max guests: [number]
- Check-in time: [e.g., 4:00 PM]
- Checkout time: [e.g., 11:00 AM]
- Entry method: [e.g., "Smart lock, code sent via message"]
- Parking: [e.g., "One assigned spot in the underground garage, space #14"]
- Wi-Fi network/password: [name / password]
- Key amenities: [e.g., "hot tub, full kitchen, ski storage, washer/dryer"]
- Nearby highlights: [e.g., "2-minute walk to lake, 10-minute drive to ski resort, restaurants within walking distance"]
- House rules: [e.g., "No smoking, no pets, quiet hours 10pm-8am, max 4 guests"]
- Checkout tasks: [e.g., "Start dishwasher, take trash to dumpster by garage, lock door"]
- Platform(s): [Airbnb, VRBO, direct booking, etc.]

My communication style is: [e.g., "Warm and casual, but professional" / "Friendly and brief" / "Detailed and thorough"]

Using these details, generate customized versions of the following messages:
1. Standard inquiry response
2. Booking confirmation
3. Pre-arrival message (with directions and full check-in details)
4. Check-in day reminder
5. Mid-stay check-in
6. Checkout reminder
7. Post-stay thank you and review request

Make each message sound like me, not like a template. Use my property details naturally — don't just fill in blanks. Keep messages concise and scannable.

Prompt 2: Adapt Your Tone for a Different Platform

I'm a short-term rental host. I have a set of guest messages written for [Airbnb / VRBO / direct booking]. I need to adapt them for [target platform].

Here are my current messages:
[Paste your messages here]

Adapt them for [target platform] with these considerations:
- Adjust the tone to match [platform] guest expectations (Airbnb tends to be more casual, VRBO guests often expect more detail, direct booking guests may need more property info since they didn't see a listing)
- Reference the correct platform name for review requests
- Adjust any platform-specific references (e.g., "message me through the app" vs. "reply to this email")
- Keep my voice consistent across platforms

Output the adapted versions, noting what changed and why.

Prompt 3: Generate Seasonal Variations

I'm a short-term rental host in [location]. I need seasonal variations of my guest messages for:
- [Season 1, e.g., "Winter / ski season (December - March)"]
- [Season 2, e.g., "Summer (June - August)"]
- [Season 3, if applicable, e.g., "Fall foliage season (September - October)"]

Here is my standard pre-arrival message:
[Paste your pre-arrival message]

Here is my standard booking confirmation:
[Paste your booking confirmation]

For each season, generate updated versions that:
- Reference relevant seasonal activities, events, and tips
- Include season-specific practical info (road conditions, weather gear, sunscreen, etc.)
- Adjust the tone to match the season's vibe (cozy for winter, adventurous for summer, etc.)
- Add any seasonal house rules or property notes (e.g., "boots on the mat please" for winter, "close windows before running AC" for summer)
- Keep the core check-in details unchanged

Output each seasonal version clearly labeled.

Prompt 4: Write a Response to a Difficult Guest Message

I'm a short-term rental host and I received a difficult message from a guest. I need help crafting a professional, calm response.

Here is the guest's message:
[Paste the guest's message]

Context:
- What happened: [Brief factual description of the situation]
- What I've already done: [Any steps taken]
- What I'm willing to offer: [e.g., "partial refund," "nothing — the complaint isn't valid," "a discount on a future stay"]
- Platform: [Airbnb / VRBO / direct]

Write a response that:
- Acknowledges their concern without admitting fault (unless I should)
- Stays factual and professional — no defensiveness or sarcasm
- Proposes a clear resolution or next step
- Keeps the door open for a reasonable outcome
- Is brief — under 150 words

Also flag if I should involve the platform's support team or if this is better handled directly.

Prompt 5: Create an FAQ Auto-Response

I'm a short-term rental host and I keep getting the same questions from guests. I want to create a single FAQ message I can send (or include in my listing) that covers the most common questions.

Here are the questions I get most often:
1. [e.g., "How do I get in?"]
2. [e.g., "Where do I park?"]
3. [e.g., "What's the Wi-Fi password?"]
4. [e.g., "Is there a coffee maker?"]
5. [e.g., "What's nearby?"]
6. [e.g., "Can I check in early?"]
7. [Add your own]

My property details: [Brief description or paste your pre-arrival message for reference]

Write a clean, scannable FAQ that:
- Answers each question in 1-2 sentences
- Uses headers or bold for each question so guests can scan
- Has a friendly but efficient tone
- Is formatted for [Airbnb message / listing description / printed house guide]
- Is under 500 words total

Prompt 6: Translate Messages for International Guests

I'm a short-term rental host and I have an upcoming guest who communicates in [language, e.g., "Spanish" / "French" / "Portuguese"].

Here is my pre-arrival message in English:
[Paste your message]

Translate it into [language] with these guidelines:
- Keep the tone warm and welcoming — match the cultural communication style
- Use formal/informal address appropriately for the culture (e.g., "usted" vs. "tú" in Spanish)
- Keep all property details (codes, addresses, times) exactly as-is — don't translate proper nouns or codes
- Add a note at the end in [language] that says "If you prefer to communicate in English, I'm happy to do that too!"

Output the translation, then a brief note about any cultural considerations I should be aware of for hosting guests from [country/region].

Prompt 7: Turn Your Messages Into Platform Automations

I'm a short-term rental host on [Airbnb / VRBO / both]. I want to set up automated scheduled messages so I don't have to manually send every communication.

Here are my messages:
[Paste all your customized messages, labeled by type]

For each message, tell me:
1. The exact trigger/timing for the automation:
   - How many days before/after check-in or checkout
   - What time of day to send
2. Which messages should stay manual (and why)
3. Any platform-specific setup steps for [Airbnb / VRBO]
4. Which messages I should review before they auto-send (vs. fully hands-off)

Format this as a simple automation schedule I can follow when setting it up on the platform.
