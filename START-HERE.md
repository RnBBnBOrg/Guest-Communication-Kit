# Welcome to the Guest Communication Kit

You're 45 minutes away from a fully customized message set for your property.

**Start here:** Open [`guides/quick-start.md`](guides/quick-start.md) for step-by-step instructions.

## What's in the box

| Folder | What's inside |
|--------|---------------|
| `templates/` | 8 template sets covering every guest message from inquiry to issue handling |
| `prompts/` | 7 AI prompts to customize everything for your property, platform, and voice |
| `guides/` | Quick-start guide with Airbnb/VRBO automation setup instructions |

## Fastest path to done

1. Open `guides/quick-start.md`
2. Gather your property details (address, check-in code, Wi-Fi, etc.)
3. Copy Prompt 1 from `prompts/message-customizer.md` into ChatGPT, Claude, or any AI tool
4. Fill in your property details and run it
5. Paste the customized messages into your platform's scheduled messages

Questions? Open an issue at https://github.com/RnBBnBOrg/Guest-Communication-Kit
